# 윤지의 할 일 목록

빌드 도구 없이 순수 HTML · CSS · JavaScript로 만든 할 일(todo) 앱이에요.
할 일은 [Supabase](https://supabase.com) 데이터베이스에 저장돼서, 새로고침하거나 다른 기기에서 열어도 그대로 남아 있어요.

👉 **사이트 주소:** https://todo-kim-yun-ji.vercel.app

## 할 수 있는 일

- **할 일 추가 · 완료 체크 · 삭제**: 바꾼 내용은 바로 데이터베이스에 저장돼요.
- **작성자 이름 붙이기 (선택)**: "윤지: 운동 30분 하기"처럼 이름이 할 일 앞에 붙어요.
- **마감 날짜 · 시각 정하기 (선택)**: 마감이 가까운 할 일이 위에 오고, 마감이 없는 할 일은 아래쪽에 모여요.
- **마감 경고**
  - 마감까지 1시간 이내: "⏰ N분 남음" 표시와 함께 카드 테두리가 경고등처럼 빨갛게 깜빡여요.
  - 마감이 지남: "마감 지남"이 빨간색으로 표시돼요.
  - 완료한 할 일에는 경고가 뜨지 않아요.
  - 새로고침하지 않아도 1분마다 자동으로 다시 확인해요.
- **글자 두 번 눌러 고치기**: Enter를 누르면 저장, Esc를 누르면 취소예요.
- **전체 · 진행 중 · 완료 보기**: 버튼으로 골라 볼 수 있고, 남은 할 일 개수도 보여 줘요.
- **오류 안내**: 저장이나 불러오기에 실패하면 입력칸 아래 빨간 상자로 알려 줘요.

## 사용한 기술

| 기술 | 하는 일 |
|---|---|
| HTML · CSS · JavaScript | 화면과 동작 (빌드 도구 없음) |
| [Supabase](https://supabase.com) | 할 일을 저장하는 데이터베이스 |
| [Vercel](https://vercel.com) | 사이트를 인터넷에 올리는 배포 서비스 |

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면의 뼈대 (입력칸, 보기 버튼, 목록) |
| `style.css` | 화면 꾸미기 (색, 배치, 깜빡이는 경고 애니메이션) |
| `app.js` | 앱의 동작 (Supabase에 저장 · 불러오기, 정렬, 마감 계산, 보기 바꾸기) |
| `config.js` | Supabase 접속 주소와 공개용 열쇠(publishable key) |
| `CLAUDE.md` | Claude Code에게 주는 프로젝트 안내 |

## 데이터베이스 구조

Supabase의 `todos` 표에 할 일 하나가 한 줄로 저장돼요.

| 칸 | 종류 | 뜻 |
|---|---|---|
| `id` | 숫자 | 할 일마다 자동으로 붙는 번호 |
| `text` | 글자 | 할 일 내용 (비워 둘 수 없음) |
| `done` | 참/거짓 | 완료했는지 (기본값: 안 끝남) |
| `author` | 글자 | 작성자 이름 (비워 둘 수 있음) |
| `due_at` | 날짜 · 시각 | 마감 (비워 둘 수 있음) |
| `created_at` | 날짜 · 시각 | 추가한 시각 (자동으로 기록) |

> 표에는 `due_date`(날짜만 담던 예전 마감 칸)도 남아 있지만, 지금 앱은 쓰지 않아요.

## 내 컴퓨터에서 실행하기

설치할 것이 없어요. `index.html` 파일을 두 번 눌러 브라우저로 열면 돼요.
화면은 내 컴퓨터에서 열리지만 할 일은 인터넷의 Supabase에 저장되니까, 사이트와 같은 할 일이 보여요.

## 배포

GitHub의 `main` 브랜치에 푸시하면 Vercel이 알아서 새 버전을 사이트에 올려요.
사이트에 예전 화면이 보이면 `Cmd + Shift + R`(Windows는 `Ctrl + Shift + R`)로 강력 새로고침을 해 보세요.

## 보안 안내

**`config.js`의 열쇠는 공개해도 괜찮아요.**
`sb_publishable_…`로 시작하는 publishable key는 웹페이지에 넣으라고 만든 **공개용 열쇠**예요.
사이트를 여는 사람은 누구나 볼 수 있고, 숨길 필요가 없어요.
반대로 `sb_secret_…`로 시작하는 secret key나 데이터베이스 비밀번호는 **절대 이 저장소에 넣으면 안 돼요.**

**⚠️ 지금은 누구나 할 일을 읽고, 쓰고, 지울 수 있어요.**
이 앱에는 로그인이 없고, Supabase 권한 규칙(RLS)이 "로그인하지 않아도 누구나 읽기 · 추가 · 수정 · 삭제 가능"으로 설정돼 있어요.
그래서 사이트 주소를 아는 사람은 누구나:

- 모든 할 일을 보고, 고치고, 지울 수 있어요.
- 다른 사람의 이름으로 할 일을 쓸 수 있어요.

혼자 또는 친구 몇 명과 쓰는 연습용으로는 괜찮지만, 여러 사람에게 공개하려면
로그인 기능을 넣고 "자기 할 일만 고치고 지울 수 있게" 권한 규칙을 좁히는 게 좋아요.
